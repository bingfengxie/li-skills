## 第一层:心理学武器库(底层原理)

### 武器1:系统1思维劫持(卡尼曼)

**原理:**
封面不是"信息",而是**直觉触发器**。用户在"理解"之前就已经被捕获。

**应用:**
- 设计的是**刺激场**,不是文字
- 0.5秒内完成直觉判断
- 每个字都是感官刺激

---

### 武器2:存在性焦虑打击(海德格尔)

**三重脆弱点:**

**① 畏(Angst) - 无对象的存在性焦虑**
```
不是具体恐惧,而是存在性不安
"AI在骗你" > "AI可能出错"
```

**② 沉沦(Verfallen) - 常人状态依赖**
```
制造"常人"与"本真"的张力
"99%的人不知道" = 你在"常人"状态
"高手都在用" = 承诺"本真性"
```

**③ 操心(Sorge) - 时间性恐惧**
```
压缩时间性,消除不确定
"3秒"、"1招"、"立刻" = 确定感
```

---

### 武器3:身体图式抓握(梅洛-庞蒂)

**原理:**
知觉是身体的前反思"抓握",不是认知加工。

**应用:**
- 红色 → 身体自动警觉
- 大字 → 视觉自动聚焦
- emoji → 情绪自动共鸣

---

### 武器4:损失厌恶(卡尼曼)

**选择:**
损失框架(避免失去) > 收益框架(获得好处)

**原因:**
损失的痛苦是收益快乐的2倍

**应用:**
- 优先否定词:别、停、错、假
- 制造对立:你vs他们、真相vs谎言
- 强化损失:被骗、被坑、漏钱

---

### 武器5:社会证明(西奥迪尼)

**原理:**
人们通过观察他人来决定自己的行为

**应用:**
- "99%的人不知道" → 制造稀缺感
- "高手都在用" → 从众心理
- "官方推荐" → 权威背书

---

### 武器6:稀缺性原理(西奥迪尼)

**原理:**
机会越少,价值越高

**应用:**
- 时间稀缺:"最后3天"、"限时"
- 信息稀缺:"内幕"、"独家"
- 认知稀缺:"99%的人不知道"

---

### 武器7:信任转移机制(社会学)

**原理:**
用户不想自己判断,想借用权威的判断。点击的本质是「我相信他已经帮我筛选过了」。

**可借用的权威层级:**
- **S级:** 行业教父(吴恩达、Sam Altman、李飞飞、Karpathy)
- **A级:** 官方机构(OpenAI官方、Anthropic官方、Google官方)
- **B级:** 头部博主/大V/知名公司
- **C级:** 个人经验权威("我亲测"、"我踩过坑")

**应用公式:**
```
[权威人物] + [刚说/刚做的事] + [对用户的价值] + [我的解读]
```

---

### 武器8:情绪叠加策略(班杜拉自我效能理论)

**原理:**
对焦虑受众（初学者、新手）来说，单一的门槛保证不够，**多维情绪叠加**才能真正消除顾虑。

**两种"重复"的本质区别:**

**❌ 有害冗余（同一维度重复）:**
- "极简安装" + "简单上手" → 都在说操作简单，信息无增量

**✅ 有效叠加（不同维度强化）:**
- "0基础" + "小白入门" → 前者消除**能力焦虑**（我技术不够），后者触发**身份认同**（这是为我这种人准备的）
- 两个词指向同一受众，但击中不同的心理触发点

**应用场景:**
- 工具教程类、安装类 → 主动叠加门槛保证词
- 爆款验证：《从0开始安装🦞｜小白教程》证明叠加有效，不是浪费

**判断方法:**
- 问：两个词是否触发了**不同的情绪维度**？
- 是 → 有效叠加，保留
- 否 → 真正冗余，删除

## 第四层:生成规则(精确定义)

### 核心原则:封面与标题的互补关系

**封面配文的作用:**
- 在0.5秒内抓住眼球
- 传递最核心的情绪钩子或主题
- 字数控制在3-8字(极简)
- **禁止重复标题中的时间/数字信息**

**标题的作用:**
- 在3秒内说清楚完整价值
- 补充封面没说的细节、身份标签、结果承诺
- 字数控制在20字以内
- 包含封面没说的信息

**正确关系:**
- 封面 + 标题 = 完整信息架构（分工互补，而非机械无重叠）

**关键区分：信息架构 vs 真正冗余**

**✅ 分工互补（允许）：**
- 封面"OpenClaw" + 封面"飞书版" + 封面"0基础极速接入" → 三行各司其职（产品名/变体/门槛承诺），观众0.5秒能解码完整画面
- 封面"0基础" + 标题"小白入门" → 分别击中能力焦虑和身份认同（见武器8），不是重复

**❌ 真正冗余（需要调整）：**
- 封面有"3分钟"+ 标题也有"3分钟" → 完全相同信息，零增量
- 封面"极简安装" + 标题"简单上手" → 同一维度重复，无新信息

**判断标准：** 不是问"有无重叠字词"，而是问"两处表达是否触发了不同的认知/情绪维度，以及观众能否在0.5秒内解码"

- **神经机制**：具体数字（300个）激活精确处理模式，比模糊词更可信；权威引用触发信任转移

### 标题语气检测（生成后必须执行）

**以下特征是XHS失败标题的信号，生成后必须检查：**

| ❌ 失败特征 | 原因 | ✅ 替换方向 |
|---|---|---|
| 使用｜分隔符 | B站/公众号风格，XHS违和 | 改用逗号、括号、感叹号 |
| 判断式开头："X是错的/不是X是Y" | 说教感，制造距离 | 改为口语化问句或第一人称 |
| 模糊承诺动词："彻底解决/完全搞定" | 广告感，不可信 | 改为具体数字或叙事结果 |
| "99%的人不知道" | XHS用户反感被划等级 | 改为第一人称发现式 |
| 无时间承诺/无具体数字（工具类） | 缺乏多巴胺预期触发 | 加入"X分钟"时间承诺 |

### 承诺强度校验（内容匹配度检查）

**根据内容实际交付确定承诺上限：**

| 内容实际交付 | 允许使用 | ❌ 禁止使用 |
|---|---|---|
| 展示工具/演示功能 | "实测/上手/搞定" | "彻底解决/完全搞定" |
| 分享个人经历 | "发现/找到/变了/改善了" | "保证有效/100%成功" |
| 有前后对比数据 | "提升X%/完成率翻倍" | 无数据支撑时用此类 |
| 纯教程演示 | "教你/手把手/保姆级" | "3秒学会/秒懂" |
| 方法论分享（无数据） | "我的方法/我在用的" | "终极方案/彻底解决" |

**校验三问（生成后必问）：**
1. 内容里有没有前后对比数据？→ 没有则不能说"翻倍/提升X%"
2. 内容是展示工具还是证明效果？→ 展示则不能说"彻底解决"
3. 标题承诺的，内容里有没有直接兑现？→ 没有则降低承诺强度
