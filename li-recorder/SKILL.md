# 选题推荐 + 记录系统

基于 35 个爆款视频数据分析出的 13 个模板库，帮你快速匹配选题方向，并格式化记录到选题记录箱。

## 工作流程

### 第一步：读取模板库

读取 `01-内容生产/选题管理/00-选题记录.md` 前半部分（模板库区域），获取 13 个模板的完整信息，包括标题公式、内容结构、关键要素和数据特征。

### 第二步：分析想法 + 匹配模板

根据用户提供的粗糙想法，从以下维度判断最合适的模板：

**内容类型判断**：
- 新工具/首测 → 国外顶流新工具首测型 or 极简安装教程型
- 观点/反常识 → 反常识观点型 or 名人访谈解读型
- 方法论/经验 → 三步法方法论型 or 痛点解决型
- 资源/工具清单 → 资源推荐型
- 概念科普 → 科普类-时间承诺型 or 科普类-概念解释型
- 提示词技巧 → 提示词模板型
- 省钱/省时 → 省钱攻略型
- 个人经历/vlog → 黑客松经历型 or 周更vlog型

**如果用户说明了目标**，根据决策树优先推荐：
- 高点赞（>5000）→ 模板1、2、3
- 高涨粉（>2.5%）→ 模板3、8、12、13
- 高收藏（比值>1.5）→ 模板10、6、2、4

### 第三步：输出推荐方案

推荐 2-3 个最合适的方案，每个方案包含：

```
**方案X：[模板名]**
- 标题示例：[套用公式后的具体标题]
- 内容结构：[3-4个核心步骤]
- 预期数据：点赞 XXXX-XXXX，收藏比 X.X+，涨粉率 X%
- 推荐理由：[1-2句话说明为什么适合这个想法]
```

然后询问用户：选哪个方案？还是有调整？

### 第四步：格式化记录

用户确认后（或用户直接要求记录，跳过确认），将选题追加写入 `01-内容生产/选题管理/00-选题记录.md` 的 `## 📝 待深化选题` 区域末尾。

**记录格式**：
```
- [ ] [选题名] - [一句话描述]（模板：X型，预估点赞XXXX-XXXX，收藏比X.X+）
```

**示例**：
```
- [ ] 从零搭建 MCP Server - 手把手教程，完全免费（模板：极简安装教程型，预估点赞3000-7000，收藏比1.5+）
```

写入后告知用户已记录成功，并提示下一步可以用 `深化选题:[选题名]` 来生成大纲。

## 注意事项

- 如果用户只是想快速记录、不需要模板推荐，可以跳过第二、三步直接记录，格式保持升级版（带模板标注）
- 商单内容优先考虑已有方向，不强行套模板，但可以参考最相近的模板数据做预期
- 模板匹配是建议，不是限制，用户可以自己选择或混合模板
